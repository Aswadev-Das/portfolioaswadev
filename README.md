# Personal portfolio website

A responsive, single-page portfolio with a deep blue-purple color theme.

## Personalize it

Open `index.html` and replace the sample text and links:

- Update any text in `index.html` as needed; the site is personalized for Aswadev M Das

- Contact email: `aswadevmdas@gmail.com`

## Add your photo

Put your image in `assets` and name it `profile.jpg`. A portrait crop works best. If the image is missing, the page displays a designed initials placeholder.

## Preview

Open `index.html` in a browser. No build step or dependencies are required. To publish with GitHub Pages, upload the contents of this folder to a repository and enable Pages in the repository settings.
